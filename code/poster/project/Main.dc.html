4Closest work & gap

Facade (CHI'17) prints overlays for appliance panels with visible labels; VizLens (UIST'16) needs a phone at every use. On switchboards the function is invisible. Our gap: caregiver-in-the-loop with confidence + verification, and a braille-free, height-coded vocabulary (54 sources).

5Key design decisions

  • AI never infers function: a wrong cap is a silent error
  • "I flipped it" turns assigned into tested
  • Bands, not %: no fake precision
  • Planted-error probe measures reliance

EN/हिंदी: which cap goes where

v1 vocabulary: light = dome 1.5 mm · fan = cross 1.1 mm · socket = triangle 1.25 mm · other = square 0.9 mm. Changed from dot/line because ISO 24503 reads dot = start/ON, bar = stop. Each shape has its own height (after Wabiński 2022); P1 tests confusions. ≈ 0.4 g PLA ≈ ₹0.5 per cap.

7AI pipeline

M1 photo checks → M2 find & straighten plate → M3 proposals + learned verifier (HOG + logistic regression) → bands: sure / check / guess → M4 S1…Sn → M5 human confirmation → M6 caps → M7 guide → M8 consented logs. ≈ 0.2 s on a CPU, offline.

8Human–AI hand-over

  • AI output starts pending; bulk-keep only for green, amber/red one by one
  • AI never assigns a function; each switch must be flipped and ticked "I checked"
  • Redraw / add / undo, no restart; confirm blocked until valid (9/9 tests)
  • Grounded in Kay 2016, Bansal 2021, Buçinca 2021, Zhang 2020

No rewiring, removable, non-conductive. Board photos only, processed on the laptop; IDs-only logs. Vocabulary is data, so new shapes need no code.

12Conclusion

The AI sees where; people decide what. Daily use stays low-tech: four shapes at four heights, no phone, no power, no rewiring. Next: 300 real photos → YOLO comparison, week-long recall, TPU sleeves per brand.
