4Closest work & gap

Facade (CHI'17) prints overlays for appliance panels with visible labels; VizLens (UIST'16) needs a phone at every use. On switchboards the function is invisible. Our gap: caregiver-in-the-loop with confidence + verification, and a braille-free, height-coded vocabulary (54 sources).

5Key design decisions

  • AI never infers function: a wrong sticker is a silent error
  • "I flipped it" turns assigned into tested
  • Bands, not %: no fake precision
  • 25% seeded AI errors, bare vs confidence, measure reliance

4 Stickers + guide
EN/हिंदी: which sticker goes where

Sticker code v1, all off the shelf: light = one bump · fan = two bumps · socket = three bumps · other = rough hook-and-loop square. No bar, because ISO 24503 reads bar = stop. P1 measures confusions; refine_vocabulary.py swaps any sticker under 90% recall. 3D-printed caps = optional upgrade.

7AI pipeline

M1 photo checks → M2 find & straighten plate → M3 proposals + learned verifier (HOG + logistic regression) → bands: sure / check / guess → M4 S1…Sn → M5 human confirmation → M6 sticker map → M7 guide → M8 consented logs. ≈ 0.2 s on a CPU, offline.

8Human–AI hand-over

  • AI output starts pending; bulk-keep only for green, amber/red one by one
  • AI never assigns a function; each switch must be flipped and ticked "I checked"
  • Redraw / add / undo, no restart; confirm blocked until valid (12/12 tests)
  • Grounded in Kay 2016, Bansal 2021, Buçinca 2021, Zhang 2020

No rewiring, removable, non-conductive. Board photos only, processed on the laptop; IDs-only logs. The code is data, so new stickers need no code changes.

12Conclusion

The AI sees where; people decide what. Daily use stays low-tech: four stickers you can buy, no phone, no power, no rewiring. The human-AI test: does showing the AI's confidence stop its mistakes reaching the wall? Next: real photos → YOLO comparison, week-long recall.
