Set up a switchboard in four steps

Take one photo. The AI marks where the switches are. You decide what each switch controls and check it by flipping it. SPARSH then prints which tactile sticker goes on which switch.

  • Stand straight in front of the board; let it fill most of the photo.
  • Turn the room light on. Avoid flash glare on glossy plates.
  • One board per photo.
